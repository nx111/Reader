# 本地书库与阅读导航

本次实现保留 Win32/GDI+ 阅读器、现有格式解析器和文本排版，不复制原书、不增加封面墙。

## 使用

- 取消顶部菜单行，书库、目录、查找、书签、显示与主题、专注、更多位于左侧图标＋文字导航，返回／前进位于导航底部。窄窗及书内面板打开时回退为图标轨。Alt／F10 聚焦更多，旧命令与快捷键继续可用。详见 [左侧导航、轻量功能与 PDF](left-navigation-pdf.md)。
- `Ctrl+L` 打开本地书库；可批量添加文件或递归添加文件夹。默认索引原路径，跳过目录链接以避免递归环。扫描、文件身份读取和 EPUB/MOBI 元数据读取在后台运行，队列最多 128 项，界面每次接收最多 24 项；可停止。阅读器加载书籍、编辑正文或显示主窗口模态对话框时暂停接收，避免缓存指针在使用中移动。
- 列表显示书名、作者、格式、进度、最近阅读、状态、原文件。书名缺省取文件名，缺失作者和历史阅读时间显示“—”。点击列标题切换排序；搜索书名、作者、路径；筛选全部、在读、已读、收藏、失联。筛选使用紧凑下拉，与主导航共用一套视觉；图标操作保留名称与工具提示。双击或 Enter 继续阅读，Delete 移出书库。
- “移出书库”移除该记录及其书签，始终保留磁盘文件。失联文件不会在启动或打开时被自动移除。选中失联记录后可重新关联；新路径已在书库中时，确认后保留失联记录的身份和进度，合并收藏与书签，并将另一进度保存为书签。书签容量不足时整个合并失败，原记录不变。
- `Ctrl+T` 切换目录。宽度达到 700 个逻辑像素时目录与正文并排，否则为覆盖式抽屉；正文点击、Esc 或再次点击目录按钮可关闭抽屉。选择章节后目录保持打开。翻页只同步章节高亮，不把焦点转入目录，也不改写阅读位置或目录滚动位置。
- 滚轮按鼠标所在区域分发。目录内滚动目录，正文内继续原有阅读／透明度操作。
- `Alt+Left` 返回、`Alt+Right` 前进；目录、章节快捷键、查找、书签、进度跳转共用当前书籍本次会话的导航历史（最多 100 项）。普通翻页不增加跳转项，返回后可前进到离开时实际阅读的位置；新跳转清除前进分支。永久书签独立保存。网络章节使用章节号与章内位置，取章失败不消耗历史。
- `F8` 进入／退出专注；全屏、无边框默认继续保持专注。从专注中临时打开目录，关闭后恢复专注。侧栏、窗口宽度、字体变化保留当前字符锚点。
- 透明模式中显示原生子控件时临时使用常规整体透明绘制；隐藏界面后恢复原来的 `UpdateLayeredWindow` 逐像素透明路径。透明度配置保留。

侧栏滚动条、可拖动分隔条、明暗风格、绘制隔离及本轮本地验证详见 [侧栏与主题说明](sidebar-theme-render.md)。

## 缓存迁移与恢复

缓存仍是程序目录中的 `.cache.dat`，仍采用原来的 XOR 编码 JSON。根字段 `schema_version` 为 5，书籍 `id` 为持久递增身份，排序、打开、删除其他书籍不修改该身份，清空后也不重用 ID。`get_item(row)` 仅用于枚举，按身份访问使用 `get_by_id(id)`。

无版本旧缓存作为版本 1 读取，保持书籍顺序、阅读位置、全部书签和设置。旧版本把当前书移至首行，却可能记录移动前的行号，因此迁移以首行恢复原有继续阅读行为。没有可靠历史时间的数据保持 `last_read=0`；不会用文件时间或旧顺序推算阅读时间。

第一次实际写入迁移数据前，根据源版本保留 `.cache.dat.v1.bak`、`.cache.dat.v2.bak` 、`.cache.dat.v3.bak` 或 `.cache.dat.v4.bak`，以后不覆盖该版本的迁移备份。版本 2 的稳定 ID、顺序、位置、书签和时间原样保留；版本 3 新增可选的稀疏书签详情，不扩大每条书籍记录；版本 4 新增根 `ui` 的主题、自定义正文配色开关及逻辑侧栏宽度，迁移继续保留原正文配色；版本 5 增加可选书签备注和 PDF 页内视图状态。每次变更先完整写入临时文件并刷新，再生成上一版 `.cache.dat.bak`，最后替换主文件。写入、刷新、备份或替换失败不会推进内存中的已保存快照，下次保存会重试。发现文件在读取后被外部修改时拒绝覆盖。损坏、截断、计数不符或较新版本的缓存会拒绝加载，保留原文件并提示恢复，不会静默初始化为空书库。

恢复时先退出程序并保存当前文件副本，再将所需 `.bak`、`.v1.bak`、`.v2.bak` 、`.v3.bak` 或 `.v4.bak` 复制为 `.cache.dat`。回退到旧程序前应恢复旧缓存副本，避免旧程序改写新身份或书签详情；前阶段程序会拒绝较新的版本，不能通过手改版本号绕过。

## 边界与验证

- 沿用应用的 `MAX_PATH` 限制；超过路径长度、空文件、非支持扩展名会跳过。元数据失败不阻止索引；EPUB 元数据 XML 限 2 MiB，MOBI 元数据读取限 64 MiB 原文件，其余使用文件名回退。
- 不解析完整正文来批量计算进度；尚未打开的旧记录显示字符位置，首次成功打开后记录正文长度。Web 进度标为“本章”，在线书标为“已加载”；第三阶段的查找明确限制在在线当前章节；即使内存中已缓存多章，也不把其他章包含在当前章搜索里。
- 缓存上限为 100000 条记录及 128 MiB 编码 JSON；超过保存大小限制会报错并保留原缓存。
- 可移植回归使用生产 `Cache.cpp`、`Jsondata.cpp`、实际导入与导航桥接函数和几何／筛选／排序实现；Win32 文件系统为故障注入替身。覆盖迁移、备份、损坏保护、稳定 ID、路径及文件身份去重、重关联合并、写入故障、外部修改、筛选排序、2 万条导入、当前阅读指针重绑定、导航分支／异步失败、100/125/150/200% DPI 几何。
- Linux 中的 MinGW 检查仅验证 Windows API 类型／语法，使用临时资源编码和 MSVC 兼容适配；不是 MSVC 链接构建。真实 Windows 正常／全屏／无边框／透明模式、鼠标键盘焦点、实际重排和跨显示器 DPI 操作仍须人工验证，不能把上述便携测试视为 GUI 通过。

Windows 验证重点：在 300×500 与宽窗口间切换并开合目录、调字体后保持阅读锚点；目录键盘和滚轮不劫持正文焦点；查找／书签／进度连续跳转后返回与前进；跨 Web 章节返回遇到成功和失败两种请求；四种窗口模式中打开／关闭界面并确认透明路径恢复；导入大文件夹时滚动、搜索、停止、打开书籍、移出及重新关联。

## 第三阶段：搜索结果、书签与批量管理

`Ctrl+F` 打开正文搜索结果窗口。支持字面搜索、大小写选项、准确结果数量、章节、上下文和字符位置；无结果有明确反馈。最多显示前 5000 项，但继续统计完整数量。结果列表用背景色和“【】”标记命中，正文在普通模式使用黄色背景、逐像素透明模式使用橙色文字。双击或 Enter 跳转，F3／Shift+F3 前后选择，跳转仍可返回／前进。

搜索在后台处理书籍快照；取消、重复请求、换书、换网络章节、正文修改均使旧请求失效。Esc 搜索中先取消，再次 Esc 关闭；Tab 保留原生控件遍历，按钮获得焦点时 Enter 激活该按钮（包括取消按钮）。本地可重排文本范围是完整当前书籍，PDF 范围是当前页的可提取文字（无 OCR），网络范围是当前章，目录尚未就绪时不会退回已缓存全文。

新书签持久保存章名和一段摘要。网络书签保存章节号与章内位置，可从其他章节返回；旧本地书签可从正文补展示信息，旧 Web 书签没有可验证章号时明确标为未知，不虚构原章节。删除、重关联、合并和正文缓存插入会同步维护详情，合并容量不足仍保留原记录。

书库支持 Ctrl／Shift 多选、Ctrl+A 全选，排序及刷新按稳定 ID 保留可见选择。收藏菜单明确区分设为收藏和取消收藏，阅读状态菜单提供未读／在读／已读，重复设置不会反向切换或重置锚点。批量移出默认取消，需要确认，保留磁盘文件；只压缩一次记录并重绑定当前阅读位置。移出正在加载的书籍会取消该加载，迟到结果凭请求编号被丢弃。导入时停止或 Esc 会立即丢弃尚未入库的队列，保留已完成记录。

第三阶段补充验证：v1/v2 到 v3 的备份、书签详情往返与损坏保护、不同章节同位置去重、摘要 UTF-16 边界、批量重复／陈旧 ID、当前书重绑定与加载取消、搜索精确计数和截断、无命中取消、重复请求隔离、真实范围桥接、过期结果拒绝、键盘角色映射，以及重绘保留手动未读状态。以上为可移植和静态验证，仍不替代 Windows 屏幕阅读器、焦点、颜色对比及窗口模式实机验证。

本轮增加书签可选短备注和用户主动选择路径的 TXT／Markdown 导出；PDF 的分页、缩放、依赖、缓存与验证边界见 [新说明](left-navigation-pdf.md)。
